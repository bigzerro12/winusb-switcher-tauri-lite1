## Writing standard for operations docs

- Optimize for incident response speed and release reliability.
- Use step-by-step actions with expected outcomes and rollback guidance.
- Prefer explicit commands and clear ownership handoff points.

Canonical terms to use across operations docs:

- Runtime Preparation / Runtime Prepared
- Sidecar Process
- Native Bridge
- WinUSB Switch Flow
