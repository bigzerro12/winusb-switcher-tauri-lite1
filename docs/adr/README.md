# ADR Index

Architecture Decision Records (ADRs) capture why major technical decisions were made and what trade-offs were accepted.

## Current ADRs

- `ADR-0001-sidecar-native-isolation.md` - isolate Native Bridge J-Link integration behind a Sidecar Process boundary
- `ADR-0002-target-filtered-runtime-bundling.md` - maintain full runtime source and stage target-specific bundles

## ADR authoring standard

Each ADR should include:

1. Status
2. Context
3. Decision
4. Consequences
5. Alternatives considered
